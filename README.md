# Controle de Ferramentas

Aplicativo web simples para controle de retiradas e devoluções de ferramentas do almoxarifado.

## Funcionalidades

- Formulário de retirada (ferramenta, responsável e telefone)
- Lista de ferramentas em uso com botão **Marcar como Devolvido**
- Aba de histórico com itens já devolvidos
- Persistência no navegador via LocalStorage

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço mostrado no terminal (geralmente `http://localhost:5173`).

## Build de produção

```bash
npm run build
npm run preview
```
